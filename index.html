SYSTEM ANALYSIS / CASE STUDY

逆水寒手游
内功系统拆解

从“三重随机叠加”切入，分析内功系统如何同时影响战力、成长节奏与玩家情绪。

01 / SYSTEM

系统定位

把内功放回资源池、养成、战斗与商业化组成的核心循环中，判断真实价值与体验矛盾。

02 / DIAGNOSIS

关键诊断

拆解产出、词条与洗炼三重随机，定位高投入和低确定感并存造成的挫败峰值。

03 / SOLUTION

优化方案

提出词条锁定、精华定向兑换与图鉴阶梯目标，为不同阶段补足可控反馈。

04 / VALIDATE

验证闭环

配置埋点、核心指标与回滚条件，让优化方案能被上线数据验证。

NARRATIVE DESIGN / GDD

豆豆工坊
经营叙事设计

让一家拼豆小店不只提供数值成长，也成为玩家与外婆、顾客、小镇之间的情感连接。

01 / STRUCTURE

三幕叙事

从继承老店、成长接棒到外婆归来，把等级节点转化为可感知的剧情事件。

02 / CHARACTER

角色弧线

为 14 位顾客配置叙事功能、成长变化和机制价值，让角色不只是内容消耗。

03 / LINK

机制联动

用剧情解释功能解锁，用环境、彩蛋和收集系统承载世界观，让成长具备意义。

04 / FEELING

情感闭环

以多种结局回望经营旅程，并在终局后保留持续经营的温柔空间。
